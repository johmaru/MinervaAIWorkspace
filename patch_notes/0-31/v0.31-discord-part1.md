**UmansChat v0.31 Patch Notes (1/2)**

30 commits on develop since v0.3. Focus: security audit fixes, mobile SSE resilience, LLM fallback enhancements.

**Security (Critical)**

**3 Blockers** (`a407544`)
- **run_command RCE**: Shell execution replaced with tokenize + `spawn(shell:false)`, read-only command whitelist, env var filtering
- **MCP stdio RCE**: Binary whitelist (npx/node/python/uvx/bun only), blocked dangerous flags, defense in depth
- **Docker socket escape**: Removed docker.sock mount, replaced container restart with scraper HTTP API, removed Docker CLI from Dockerfile

**CRITICAL/HIGH Round 1** (`59fcd2b`)
- Google OAuth takeover prevention (email_verified required before linking)
- IDOR fixes on threads / user-traits / memories (ownership validation)
- Login rate limiting (5 fails -> 15 min lockout)
- SearXNG secret moved to env var, security headers added (CSP, HSTS, X-Frame-Options, nosniff, Referrer-Policy)

**CRITICAL/HIGH Round 2** (`00bd68d`)
- Updater SHA256 checksum verification (mandatory)
- /api/scrape SSRF protection (private IP blocking)
- Settings POST URL validation, Host header injection mitigation
- .limit(100) on all list API endpoints (DoS prevention)

**Mobile SSE Streaming Resilience**

4 commits (`46b3fe8` -> `71b3a51`)
- Fixed SSE dying on screen-off / background on mobile
- Server: send() error-safe, LLM runs to completion + DB persists after disconnect
- Client: WakeLock, resync polling on visibilitychange/pageshow, network-error catch triggers resync, done:true disconnect detection
